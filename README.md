# ジャグラー実戦記録

パチスロ「ジャグラー」シリーズの実戦データと収支を記録し、設定を推測するための個人用ツールです。
ホールでスマホを片手で操作することを前提に作っています。

https://orica256.github.io/juggler-log/

## できること

- 着席時・離席時のデータカウンターを記録し、自分の実績を差分で自動算出
- 投資・回収・収支・時給の記録(交換率6種に対応)
- 実戦中のカウント(ぶどう / BB / 単独REG / チェリーREG / 不明REG)とリアルタイム確率表示
- 機種ごとに「数えるべき指標」を自動判定
- 履歴・累計収支・勝率の確認
- CSVによるバックアップと復元

## データの扱い

記録はすべて端末内(IndexedDB)に保存され、外部へ送信されません。
このリポジトリに収支データは含まれていません。

ブラウザのデータを消すと記録も消えます。とくに iOS Safari は7日間アクセスの無いサイトのデータを
削除するため、**「ホーム画面に追加」してから使い、CSVバックアップを定期的に取ってください**。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run dev:host   # 同一Wi-Fi内のスマホから確認する
npm test           # テスト
npm run typecheck
npm run build
```

機種マスタとアイコンは生成物です。直接編集せず、生成し直してください。

```bash
npm run machines                      # phase0-research/*.json から src/data/machines.ts を生成
python scripts/generate-icons.py      # PWA用アイコンを生成
```

## 設定推測について

- BB / RB / 合算 / 出玉率はメーカー公表相当で、複数の情報源が完全に一致しています
- **ぶどう・単独REGの確率はメーカー非公表**で、流通しているのは第三者の解析値です。
  機種によっては複数系統が並立しているため、該当機種は「暫定値」と表示します
- ぶどうの分母は通常時ゲーム数です(データカウンターの総回転数からボーナス消化ぶんを差し引いています)

数値の出典と、情報源間の食い違いは `phase0-research/` に記録してあります。
